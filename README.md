**SkyDrive** is a feature-rich, full-stack personal cloud storage platform. It enables users to organize files within a recursive folder structure, track storage limits in real-time, and manage data through a sleek, responsive interface.

🔗 **Live Demo:** [https://sky-drive-clouds.vercel.app/](https://sky-drive-clouds.vercel.app/)

---

## ✨ Features

- **Recursive Folder System:** Create, rename, and nest folders infinitely using a self-referencing relational logic.
- **Smart Storage Tracking:** Real-time visual progress bar for storage usage (100MB user limit).
- **Organization Tools:** - ⭐ **Starred:** Instant access to your most important files.
    - 🗑️ **Trash:** Safe "soft-delete" system before permanent removal.
    - 🔍 **Global Search:** Find files and folders instantly via a real-time filtering system.
- **Responsive Architecture:** Custom-built mobile sidebar and navigation designed for seamless use across all devices.
- **Secure Auth:** Industry-standard JWT authentication and salted password hashing.

---

## 🛠️ Technical Stack

### Frontend
- **React.js (Vite):** Modern, fast development and production build.
- **Tailwind CSS:** Utility-first styling for a clean, professional UI.
- **Lucide-React:** Consistent and lightweight iconography.
- **Axios:** Streamlined API communication with base URL configurations.

### Backend
- **Node.js & Express:** High-performance server environment.
- **PostgreSQL:** Relational database for complex data integrity.
- **pg (node-postgres):** Pool-based connection management for scalability.
- **Bcrypt.js:** Secure password protection.
